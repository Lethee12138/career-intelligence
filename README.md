# Career Intelligence

Career Intelligence is an MCP + Skill project for career research, job discovery, role analysis and application preparation.

It provides a capability layer for analysing career options with evidence-based workflows.

## What it can do

- Analyse job descriptions
- Explore possible role matches
- Review evidence fit
- Support application preparation

## Project structure

- `mcp/` - MCP server implementation
- `skills/` - reusable skill resources
- `rules/` - workflow and decision rules
- `schemas/` - data structures
- `workflows/` - guided processes

## Privacy

This repository contains the capability layer only.

Do not commit:

- personal CV files
- private career records
- personal evidence databases
- API keys or tokens

## Boundaries

Career Intelligence provides analysis support.

It does not:

- submit applications
- contact employers
- make decisions on behalf of users

Users should provide their own context and review outputs themselves.
