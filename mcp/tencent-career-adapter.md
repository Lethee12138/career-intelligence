# Tencent Career Adapter Blueprint

## Purpose

Map Tencent official recruitment sources into the common official source runtime.

## Current Stage

Mapped to the common runtime. The verified official host is `join.qq.com`; a Tencent-specific live parser is not enabled yet. No application action.

## Expected Fields

- company
- role
- post_id
- location
- business_group
- job_description
- requirements

## Verification

Official Tencent source required before OPEN_VERIFIED.

## Boundary

Does not decide:

- candidate fit
- application priority
- CV routing
